SOC Lab Series

Building a SOC Lab From Scratch

A self-hosted Security Operations Center lab on Proxmox — network segmentation, endpoint telemetry, IDS/IPS, SOAR automation, case management, and digital forensics, built and verified end-to-end against live traffic.

8 chapters · source on GitHub
A note on this series. This is not a tutorial — it documents real decisions, real bugs found and fixed, and real live-traffic verification for a personal SOC lab. Lab-internal IP addresses (RFC1918, 10.1.x.x) are left intact; all credentials and webhook identifiers are redacted.
  • 01 Proxmox Installation, VM Configuration, and Remote Access
    From a bare-metal machine to a virtual lab environment: Proxmox installation, disk configuration, Windows and Ubuntu VMs, and secure remote access.
  • 02 VLAN Segmentation with OPNsense and Active Directory
    Firewall deployment, VLAN-based network segmentation, and a Windows Server Active Directory domain.
  • 03 Centralized Security Monitoring with Wazuh, Sysmon, and FIM
    Deploying Wazuh as the SIEM core, Sysmon-based endpoint telemetry, and file integrity monitoring.
  • 04 Suricata IDS/IPS Integration
    Network-based intrusion detection with Suricata, rule tuning, and Wazuh integration.
  • 05 Shuffle SOAR Automation
    SOAR workflows correlating Wazuh alerts against MISP threat intelligence, with deduplication and fail-closed error handling.
  • 06 TheHive and Cortex Case Management
    Incident triage and case management with TheHive, enriched by Cortex analyzers.
  • 07 Velociraptor Digital Forensics
    Endpoint DFIR with Velociraptor — artifact collection, live investigation, and a real false-positive case study.
  • 08 MISP — Threat Intelligence and IOC Correlation
    Feed ingestion, a native TheHive sync with a real licensing bug, and three Shuffle workflows correlating Sysmon-observed hashes, domains, and IPs against MISP.
